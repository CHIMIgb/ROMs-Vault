## Objetivo
Completar la migración a `t()` en: controladores, mensajes flash, `index.php`, endpoints (`ajax_*`, `rom_proxy.php`), vistas admin restantes (`add.php`, `edit.php`, `consolas/*.php`, `categorias/*.php`, `emuladores/*.php`, `game_actions` si aplica), componentes JS con `data-i18n` y `confirm()`.

## Checklist Fase 3
- [x] **Controladores** (`src/controllers/*.php`): mensajes de error/success flash -> usar `t()` (con fallback) o pasar clave + params.
- [x] **index.php** (router): errores 404/403/genéricos -> `t()`.
- [x] **CsrfService/RateLimiter/AuthMiddleware** (mensajes) -> revisar si devuelven texto directo a UI.
- [x] **endpoints/**: `ajax_*.php`, `rom_proxy.php` -> respuestas JSON con claves i18n o traducir en cliente? (cliente espera texto en español actual; mantener compat).
- [x] **Admin vistas**: `add.php`, `edit.php`, `consolas/index.php`, `consolas/create.php`, `consolas/edit.php`, `categorias/*`, `emuladores/*`, `tfa.php` (parcial) -> completar.
- [x] **Admin listados**: filtros, estados, acciones, modales confirm.
- [x] **JS inline**: buscar `confirm(`, `alert(` hardcodeados -> `t()` via `data-i18n`.
- [x] **Flash messages**: pasar clave i18n desde controller (o traducir en vista). Preferir clave.
- [x] **Tests**: validar no rompe integración (POST con CSRF). Suite verde.
- [x] **Docs**: registro en roadmap `docs/2026-08-05-plan-mejoras-nivel-senior.md` al aplicar.
